# 🔑 Ключ — главный открытый вопрос #статус/подтверждено

После цепочки `setka` → `okno` → `kluch` появляется кнопка **«Загрузите ключ»** (открывает проводник с поиском изображений; вход дублируется через `document.getElementById('u38').click()`). Какое изображение грузить — **неизвестно** (🔴).

## Правила canvas сайта

- До **12 изображений**, накладываются слоями.
- Почти белые пиксели (**RGB ≥ 245** по каждому каналу) становятся **прозрачными**.
- Картинка подгоняется под сетку.

## Версия сценаристов (15.11.2026)

> [!fact] «Ключ — это все монстры/роботы из спойлеров» — слова команды сценаристов [15.11]
> Собирать ч/б картинки монстров/роботов из шортсов и накладывать слоями (белое → прозрачное, RGB ≥ 245; белый прозрачен даже в JPEG [15.11]).

> [!fact] Механика ключа подтверждена чатом (15.11)
> - «Ключ **закроет большую часть букв** [сетки] **и оставит нужные**» [15.11, @𝐅ацеслесс] — картинка-маска на сетку 29×29.
> - «Ждём картинку, которую нужно будет **накласть на таблицу** и получить слова/нужные буквы» [15.11].
> - В сетке должно выходить **целое предложение** (слова поодиночке — «не те», ввод «не словил») [15.11].
> - После таймера (21:00 МСК 15.11) «вроде будет **картинка**» — вероятный кандидат в ключ [15.11].

## Кандидаты и стратегия

1. **Картинки монстров/роботов из спойлеров** (версия сценаристов) — источник: кадры шортсов + 511 фото из экспорта чата 15.11.
2. PNG из «луковицы» (iVBORw0KGgo…) [15.11].
3. Значок организации / народа [[Джодах|Джодаха]] / М47 [15.11, чат].
4. QR-код, ведущий на сайт (🔮).
