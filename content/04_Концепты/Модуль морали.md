# Модуль морали #статус/подтверждено

> [!fact] Цитата спойлеров (кампания после [[Мастерская 47|М47]]):
> «**С принудительного отключения [[МИ|М.И.]] теперь у машин нет модуля морали**» [14.11].

## Проверка по канону

Поиск «модуль морали» по вики (15.11.2026) даёт только ложные совпадения («моральная черта» у Калеба, «моральной точки зрения» у Тори). **В каноне арки I/II термина нет** — это новый лор спойлерной кампании. Не мостить через прошлые сезоны.
