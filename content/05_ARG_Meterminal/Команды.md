# Команды терминала #статус/подтверждено

> Выжимка. Полная оперативная таблица — в xlsx-реестре (лист КОМАНДЫ).
> Регистр и пробелы значимы; даты — `ДДММГГГГ` без разделителей.

| Команда | Что делает | Статус | Примечания |
|---|---|---|---|
| `tma otkroet svet` | открывает таблицу с шифром (сетка) | ✅ | ASCII из шортса расшифровывается в эту же фразу |
| `setka` → `okno` → `kluch` | последовательность после таблицы → кнопка «Загрузите ключ» | ✅ | иногда не срабатывает с первого раза |
| `993` | появляется Ло; «радио» → думает; клик — машет | ✅ | |
| `993` → `game` | мини-игра «лохозавр» | ✅ | |
| `moral` | фейковая ошибка «модуль не найден»; позже — **фейк КРАШ** | ✅ | см. [[Модуль морали]]; фейк-краш — зацепка к слою 16 луковицы |
| `off` | перезагрузка страницы | ✅ | |
| `12051995`, `31121999`, `09032016` | запускают шортсы по дате | ✅ | формат `ДДММГГГГ` |
| `+86962734369` | «отвёртки закончились» | ✅ | номер из рекламы в первом спойлере |
| `Зачем ты существуешь` | лор М.И. о себе | ✅ | с большой буквы |
| транслит-фразы (`kto ti`, `ti chelovek`, `reshi zadachu`, …) | ~20 шаблонных ответов бота | ✅ | |
| калькулятор (`sqrt`, `sin`, `fact`, `pow`, `π`, `ans`, …) | считает | ✅ | |
| `__s04_e01__` | перезагрузка через 2 сек | 🟡 | служебное |

> [!fact] Ревью опубликованного сайта [16.11, чат]
> Несуществующие команды (`френ`, `мечта`) удалены из реестра по замечанию декодера.

Слово «ОКНО» мелькало в кадре шортса (на 0.2×) — совпадает с `okno` (✅ находка, контекст перепроверить).
