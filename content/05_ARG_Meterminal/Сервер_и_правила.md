# Сервер и правила #статус/подтверждено

- Все действия (команда, кнопка, ручка, рычаг) → **POST `/api/puzzle`** → сервер возвращает сцену.
- Ресурсы: `/assets/a01.js`–`a04.js` (аудио), `/api/a01.js…a05.js`, `/api/asset/01-a…05-a` (файлы идут с кодом **206** — частично), `/sctest/s17.dat` [17.10, 15.11], **`/sctest/SECRET`** — фид принтера (подсказки к луковице) [15.11 21:28].
- **`/api/scene/<id>`** — сцены подгружаются как `<script>` (app.js 15.11): перебор id не делаем, только уже известные сцены.
- **Printer-slot**: `<div class="printer-slot" data-feed="sctest/SECRET">` в HTML главной — механика «принтера» [15.11 21:28].
- Снапшот до смены домена: `web.archive.org/web/20261114082221/meterminal.pages.dev` [15.11].

> [!danger] Жёсткое правило
> **Брутфорс `/api/puzzle` запрещён правилами ARG**: повторные неверные ответы → временный бан. Перебор сцен и ответов не делаем. Код читать можно; перебор — нет. Триггеры через `mi:unlock` — только для уже известных сцен.
